Privacy policy

Last updated: 18 November 2026

brain is a personal tool used only by its developer, with their own Google account. No other users' data is accessed.

What it accesses

  • Gmail, read-only (gmail.readonly): message text and headers.
  • Google Calendar, read-only (calendar.readonly): event details.

It cannot send, change or delete email or calendar events.

How the data is used and stored

  • Copies are saved as plain files on the developer's own computer, so they can search them.
  • To make search work better, the text is summarised by Anthropic's Claude AI service. Anthropic processes this under its own terms and privacy policy.
  • The data is not sold, shared with anyone else, or used for advertising.
  • The access sign-in is stored on the developer's computer, readable only by their user account.

Google API Services User Data Policy

brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions, and the local copies deleted.
